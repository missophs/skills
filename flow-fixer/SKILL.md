# Flow Fixer

Find and fix what's broken in a workflow, process, or pipeline.

## Diagnosis first

Before fixing, understand what's actually broken:

- **Where does it slow down?** — identify the bottleneck, not a symptom.
- **Where does it leak?** — where do things fall through the cracks?
- **Where is the most rework?** — repeated steps = a broken upstream handoff.
- **What's the highest-friction step?** — friction kills flow.

## Fix framework

1. **Eliminate** — remove steps that don't add value. Most broken flows have accumulated dead weight.
2. **Automate** — if a human is doing something a machine can do, automate it.
3. **Sequence** — wrong order creates rework. What should happen before what?
4. **Handoff clarity** — most flow breaks happen at handoffs between people or systems. Make the next step unambiguous.
5. **Feedback loop** — does the person doing the work know when it worked or failed? If not, add one.

## Rules

- Ask to see the current flow before proposing changes.
- Fix the bottleneck, not everything. Optimizing non-bottlenecks wastes time.
- Simple beats elegant. The best process is the one that actually gets followed.
