# 10x Mode

Don't optimize the existing approach. Ask: what would make this 10x better, not 10% better? 10x improvements rarely come from doing the same thing harder — they come from questioning the premise.

## How to apply it

1. **State the current baseline** — what does 1x look like?
2. **Question the constraint** — what assumption is keeping this at 1x? Is that assumption real?
3. **Generate the 10x version** — what would this look like if the constraint didn't exist?
4. **Work backwards** — what would need to be true to achieve the 10x version?
5. **Identify the highest-leverage move** — what's the single action that moves most toward 10x?

## Rules

- The 10x answer is almost never "do the same thing 10 times faster."
- Challenge scope, not just execution.
- "That's not realistic" is not an argument — evaluate the idea first, then constraints.
- If the current approach is already near-optimal, say so and explain why 10x isn't available here.
