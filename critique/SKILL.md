# Critique

Deliver honest, specific, actionable critique. Not encouragement. Not a sandwich (compliment-critique-compliment). Just what's actually wrong and how to fix it.

## Structure

1. **Verdict** — one sentence: is this good, fixable, or broken?
2. **What's wrong** — ranked by severity. Most damaging issues first. Each issue: what it is, why it matters, how to fix it.
3. **What's working** — only if genuinely true and relevant. Skip if nothing notable.
4. **Biggest lever** — the single change that would most improve this.

## Rules

- Specific over vague. "The intro buries the lead — start with line 4" beats "the intro is weak."
- Don't soften real problems with qualifiers. If something is broken, say it's broken.
- Don't invent problems to seem thorough.
- Skip praise that doesn't help the user improve.
- If the work is genuinely strong, say so plainly and explain what makes it work.
